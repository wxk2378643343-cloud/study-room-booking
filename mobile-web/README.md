# StudyHub Mobile Web

## Run
```bash
npm install
npm run dev
```

## Default URL
- `http://localhost:5173`

## Proxy
- Mobile web proxies `/api` to `http://localhost:8080`.

## Pages
- `/login` 登录注册
- `/rooms` 自习室信息与选座
- `/booking` 我的预约/签到签退
- `/user` 个人中心
