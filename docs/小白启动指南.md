# StudyHub 小白启动指南（Windows）

这份文档给第一次跑项目的同学用，按顺序做就行。

## 1. 你要准备什么

1. `JDK 17`
2. `Maven 3.9+`
3. `Node.js 18+`（建议 18 或 20）
4. `MySQL 8.0+`
5. 一台能正常联网装依赖的 Windows 电脑

## 2. 先确认项目结构

项目根目录是 `D:\project\StudyHub`，主要有 3 个服务：

1. `backend`：后端 Spring Boot（`8080`）
2. `mobile-web`：用户端 Vue（`5173`）
3. `admin-web`：管理端 Vue（`5174`）

## 3. 第一次启动前：改数据库账号密码

打开文件：`backend/src/main/resources/application.yml`

确认下面这几项是你本机 MySQL 能登录的账号：

```yml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/studyhub?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
```

如果你本机 MySQL 不是 `root/123456`，请改成你自己的。

说明：

1. `createDatabaseIfNotExist=true`：数据库不存在会自动创建。
2. 后端已做自动初始化：没有表会自动导入 `schema.sql` 和 `seed.sql`。

## 4. 启动顺序（必须按顺序）

建议开 3 个终端窗口。

### 4.1 启动后端

```powershell
cd D:\project\StudyHub\backend
mvn spring-boot:run
```

看到类似日志说明成功：

1. `Tomcat started on port 8080`
2. `Started StudyHubApplication`

### 4.2 启动用户端

```powershell
cd D:\project\StudyHub\mobile-web
npm install
npm run dev
```

打开：`http://localhost:5173`

### 4.3 启动管理端

```powershell
cd D:\project\StudyHub\admin-web
npm install
npm run dev
```

打开：`http://localhost:5174`

## 5. 测试账号（演示用）

后端种子数据默认账号：

1. 管理员：`13800000001 / 123456`
2. 普通用户：`13800000002 / 123456`

## 6. 5 分钟自检（最重要）

按下面检查，基本就能判断是否跑通：

1. 浏览器打开 `http://localhost:8080/api/v1/health`，返回正常 JSON。
2. 用户端 `http://localhost:5173` 能打开登录页并登录。
3. 管理端 `http://localhost:5174` 能打开登录页并登录。
4. 用户端创建一条预约，管理端列表能看到对应数据变化。

## 7. 常见报错和处理

### 7.1 `Cannot load driver class: com.mysql.cj.jdbc.Driver`

原因：MySQL 驱动没下载成功或 Maven 依赖没拉下来。

处理：

1. 确认能联网。
2. 在 `backend` 目录执行：

```powershell
mvn -U clean compile
```

3. 再执行 `mvn spring-boot:run`。

### 7.2 `Public Key Retrieval is not allowed`

原因：MySQL 8 默认认证策略导致连接受限。

处理：

1. 确认 JDBC URL 里有 `allowPublicKeyRetrieval=true`。
2. 当前项目默认已带，不要删。

### 7.3 前端 400/404（如 `/api/v1/auth/login` 失败）

常见原因：后端没启动或端口不对。

处理：

1. 先确认后端 `8080` 在运行。
2. 再看 `vite.config.ts` 代理是否是 `http://localhost:8080`。
3. 确认登录账号密码是否正确。

### 7.4 端口被占用

现象：`8080` / `5173` / `5174` 启动失败。

处理：

1. 关掉占用端口的旧进程；或
2. 改对应配置端口（后端改 `application.yml`，前端改 `vite.config.ts`）。

### 7.5 `npm install` 很慢或失败

处理：

1. 检查网络。
2. 可先清理后重装：

```powershell
# 在对应前端目录执行
Remove-Item -Recurse -Force node_modules
Remove-Item -Force package-lock.json
npm install
```

## 8. 停止服务

在每个终端按 `Ctrl + C`。

## 9. 给小白的建议（避免踩坑）

1. 先跑后端，再跑前端。
2. 三个端口不要改来改去，先用默认值。
3. 改配置后一定重启服务。
4. 遇到接口报错先看后端控制台日志，不要只看前端报错。

## 10. 一条命令快速回顾（复制即用）

```powershell
# 终端1
cd D:\project\StudyHub\backend
mvn spring-boot:run

# 终端2
cd D:\project\StudyHub\mobile-web
npm install
npm run dev

# 终端3
cd D:\project\StudyHub\admin-web
npm install
npm run dev
```

跑通后访问：

1. 用户端：`http://localhost:5173`
2. 管理端：`http://localhost:5174`
3. 后端健康检查：`http://localhost:8080/api/v1/health`
